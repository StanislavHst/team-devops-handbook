## Завдання 1. Скрипт резервного копіювання (`backup.sh`)

### Призначення
Автоматизує створення архівів у форматі `.tar.gz`, підтримує симуляцію без змін (`--dry-run`), записує дії в журнал (`backup.log`) та очищує старі копії за лімітом (ротація).

### Пояснення прапорців `set -euo pipefail`
* **`-e` (errexit)**: Зупиняє виконання скрипту при першій же помилці будь-якої команди (якщо код повернення != 0).
  * *Що зламається без нього:* Скрипт продовжить роботу, навіть якщо `tar` не зміг створити архів, і перейде до ротації — тобто почне видаляти старі бекапи, не створивши нового.
* **`-u` (nounset)**: Трактує будь-яку неоголошену змінну як критичну помилку.
  * *Що зламається без нього:* Помилка в назві змінної (наприклад, `rm -rf "$DEST_DIR/*"`, де `$DEST_DIR` порожня через одруківку) перетвориться на `rm -rf "/*"` і видалить файли в усій системі.
* **`-o pipefail`**: Змушує пайплайн (`cmd1 | cmd2`) повертати код помилки, якщо збій стався у будь-якій частині ланцюжка, а не лише в останній команді.

### Коди виходу (Exit Codes)
* `0` — Успіх або виклик довідки (`--help`).
* `1` — Неправильні або відсутні аргументи.
* `2` — Вихідна тека не існує.
* `3` — Помилка створення/доступу до цільової теки.
* `4` — Помилка стиснення утилітою `tar`.

### Приклади використання
```bash
# Довідка
./backup.sh --help

# Тестова симуляція (dry-run)
./backup.sh --dry-run /шлях/до/даних /шлях/до/бекапів

# Запуск зі збереженням останніх 3 архівів
./backup.sh -r 3 /шлях/до/даних /шлях/до/бекапів
